# Автотесты для учебного сервиса «Яндекс.Маршруты»

Проект с автотестами на **Python + Selenium + Pytest + Allure** для учебного сервиса «Яндекс.Маршруты».

Покрываются основные пользовательские сценарии:

- отрисовка маршрута на карте;
- отображение блока с выбором маршрута;
- подготовка к заказу такси;
- заказ тарифа «Такси» (форма, тарифы, тултипы);
- полный флоу заказа такси до окна совершенного заказа.
